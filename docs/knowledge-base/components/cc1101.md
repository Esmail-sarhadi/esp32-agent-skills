# TI CC1101 Sub-GHz Transceiver Dossier

## Capability and profile

CC1101 is a configurable sub-GHz transceiver with packet handling features; it is not a LoRa modem. Record exact module band, crystal frequency, antenna network and board revision. Frequency, channel bandwidth, data rate, deviation, modulation and receive filtering must be configured as a coherent profile on both endpoints.

## RF and board design

Use the module schematic and TI reference layout guidance. Check supply decoupling, crystal tolerance, RF matching and antenna tuning for the final enclosure. Keep noisy SPI and switching power routes away from the RF section. Measure conducted output or antenna match only with appropriate RF equipment and safe test fixtures.

## Packet engine

Configure sync word, preamble, fixed/variable packet length, address filtering, CRC and whitening consistently. Bound application payloads and validate packet length before parsing. Use sequence numbers to detect duplicates and loss. FIFO overflow/underflow must be counted and recovered explicitly.

## Interrupt and SPI model

GDO signals indicate configured radio events. Keep ISR work short and defer status/FIFO SPI transactions to a task. Respect SPI mode, chip-select timing and radio state transitions. Do not issue long SPI transactions from an ISR or assume a library's default GDO mapping matches the module.

## Regulatory and field validation

Check the local frequency allocation, EIRP, channel access, duty cycle and listen-before-talk rules for the product and country. Measure packet error rate across distance, antenna orientation and interference. RSSI alone is not a reliability metric.

## Test matrix

| Scenario | Measure |
|---|---|
| Modem profile mismatch | Sync and CRC failures |
| Burst packets | FIFO overflow and loss |
| Weak signal | PER vs RSSI |
| Radio reset mid-frame | State recovery |
| Enclosure/antenna change | Link margin delta |
